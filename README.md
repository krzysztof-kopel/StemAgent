# Stem Agent
An AI agent with evolutionary features. Able to adapt to a task and find the precise solution needed. 

## Project components
- report.pdf - a report, describing my approach, architecture of the model, issues encountered and possible future extensions.
- demo.ipynb - a demonstration of the project on the exemplary input, shows the stem model superiority over traditional LLM.
- src - source files of the agent.
- resources - logs used for the demonstration of agent's capabilities.

## Project set-up
1. Copy this repository to your computer.
2. Create an .env file with your own OpenAI API key (in a format consistent with .env.example).
3. Install the necessary dependencies (preferably using uv).
4. Follow the example presented in demo.ipynb to make the agent evolve.
